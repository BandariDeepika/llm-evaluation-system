# Milestone 2.1 — Judge Implementation

## Automated LLM Evaluation and Hallucination Detection System

### 1. Objective

The objective of Milestone 2.1 is to enhance the LLM evaluation system with multiple evaluation judges that assess AI-generated responses across different quality dimensions.

The system evaluates an AI response using:

* Relevance
* Factuality / Accuracy
* Hallucination Detection
* Faithfulness
* Completeness
* Semantic Similarity

The system also supports Knowledge Base retrieval to provide relevant evidence for evaluation.

---

## 2. Evaluation Architecture

The evaluation workflow consists of the following major stages:

1. User provides a question.
2. AI-generated response is provided as evaluation input.
3. Optional reference answer and source context can be supplied.
4. Knowledge Base retrieval identifies relevant supporting information.
5. Multiple evaluation judges analyze the response.
6. Individual evaluation scores are generated.
7. Hallucination status is determined.
8. An overall evaluation score is calculated.
9. Results are displayed through the Streamlit interface.

---

## 3. Relevance Judge

The Relevance Judge evaluates whether the AI-generated response directly addresses the given question.

### Purpose

It checks whether the response is related to the user's question and avoids unnecessary or unrelated information.

### Input

* Question
* AI Response

### Output

A relevance score is generated based on how well the response addresses the question.

### Example

**Question:**
What is photosynthesis?

**Relevant Response:**
Photosynthesis is the process by which green plants use sunlight, carbon dioxide, and water to produce glucose and oxygen.

This response is considered relevant because it directly answers the question.

---

## 4. Factuality / Accuracy Judge

The Factuality Judge evaluates whether the information provided in the AI response is factually correct.

### Purpose

It compares the generated response against available reference information, source context, or retrieved knowledge.

### Input

* Question
* AI Response
* Optional Reference Answer
* Optional Source Context
* Retrieved Knowledge Base chunks

### Output

An accuracy/factuality score is generated.

### Example

**Question:**
What is the capital of France?

**Response:**
Paris is the capital of France.

This response is factually correct.

If the response states that London is the capital of France, the factuality evaluation should identify the information as incorrect.

---

## 5. Hallucination Detection Judge

The Hallucination Detection Judge identifies information in an AI response that is unsupported by the available evidence.

### Purpose

The purpose is to detect unsupported or fabricated claims.

The system compares the response with the available reference information, source context, and retrieved knowledge.

### Output

The system provides a hallucination assessment along with the evaluation result.

### Example

If the source states:

> The company was founded in 2010.

but the AI response states:

> The company was founded in 1995.

the second statement can be identified as unsupported or contradictory to the available evidence.

---

## 6. Faithfulness Evaluation

Faithfulness measures whether the generated response remains consistent with the provided source or retrieved context.

A response can be relevant to the question but still introduce information that is not supported by the source.

### Example 1

**Source:**
The device operates at 5 GHz.

**Response:**
The device operates at 5 GHz.

The response is faithful to the source.

### Example 2

**Source:**
The device operates at 5 GHz.

**Response:**
The device operates at 5 GHz and consumes 20 W of power.

If the source does not mention power consumption, the additional claim is not supported by the source.

---

## 7. Completeness Evaluation

Completeness evaluates whether the response contains the important information required to answer the question adequately.

A response may be factually correct but incomplete.

### Example

**Question:**
What are the main components required for photosynthesis?

A complete response should mention the important components such as:

* Sunlight
* Carbon dioxide
* Water
* Chlorophyll

The completeness score reflects how sufficiently the response covers the required information.

---

## 8. Semantic Similarity Evaluation

Semantic Similarity measures how closely the meaning of the generated response matches the reference answer.

The system uses semantic embeddings to compare the generated response and reference information.

The project uses the:

**`all-MiniLM-L6-v2`**

sentence-transformer model for generating embeddings.

Semantic similarity is useful because two answers can use different words while expressing the same meaning.

### Example

**Reference:**
Python is a high-level programming language.

**Generated Response:**
Python is a programming language that provides high-level abstractions.

Although the wording is different, the meaning is similar.

---

## 9. Knowledge Base Retrieval

The system supports retrieval of relevant information from a local Knowledge Base.

The retrieval process helps provide evidence that can be used during evaluation.

### Knowledge Sources

The project uses QA/reference datasets including:

* TruthfulQA
* SQuAD

Relevant chunks are retrieved based on the input question.

### Retrieval Flow

```text
Question
   ↓
Embedding / Retrieval
   ↓
Relevant Knowledge Chunks
   ↓
Evaluation Judges
   ↓
Evaluation Scores
```

The retrieved information can be used as supporting evidence when evaluating factuality, faithfulness, completeness, and hallucination.

---

## 10. Overall Evaluation

The system combines the individual evaluation dimensions to provide an overall assessment of the AI response.

The evaluation interface displays:

* Overall Score
* Relevance
* Factuality
* Faithfulness
* Completeness
* Semantic Similarity
* Hallucination status

The overall score provides a high-level view of response quality while the individual scores explain the strengths and weaknesses of the response.

---

## 11. Backend Implementation

The evaluation system uses **FastAPI** as the backend framework.

The backend is responsible for:

* Receiving evaluation requests
* Processing the input
* Running evaluation logic
* Performing Knowledge Base retrieval
* Calculating evaluation scores
* Returning evaluation results

The backend can be accessed locally through the FastAPI server during development.

---

## 12. Frontend Implementation

The project uses **Streamlit** for the user interface.

The interface allows the user to enter:

* Question
* AI Response
* Reference Answer
* Source Document / Context

It also displays:

* Retrieved chunks
* Individual evaluation scores
* Overall score
* Hallucination assessment

This provides an interactive interface for testing the evaluation system.
